# Campus Resume Skill

帮助校招生优化已有简历，或从零写出简历的轻量工具。支持不同岗位的定向调整，以及相关方向的通用投递；不承诺同一份简历适合所有岗位。

## 获取与使用

- 下载最新版 [Campus_Resume_SKILL_V0.4.1.md](./Campus_Resume_SKILL_V0.4.1.md)，或使用标准入口 [SKILL.md](./SKILL.md)。两份文件内容相同。
- 在支持自定义 Skill 的工具中按其要求加载 `SKILL.md`；也可在新对话中上传文件，请 AI 按文件规则工作。
- 已有简历：上传简历，说明“帮我优化”，或“先诊断，不要直接出全文”。
- 没有简历：说明教育背景和大致方向，零散描述做过的事情即可。
- 想海投：告诉 AI 所考虑的方向；不需要逐个提供 JD。
- 要定向投递：提供具体 JD，直接调整内容重点。

## 输出

正文基本成形后，未指定格式时会询问一次，可按需选择可编辑 Word、PDF、HTML 或 Markdown，也可以多选。实际文件能力取决于使用环境，已指定格式时直接执行。未选格式时可先拿到 Markdown 正文。默认按适合一页 A4 的内容量取舍；Markdown 本身没有固定分页。

完整交付时附关键修改说明，解释素材取舍、重排逻辑和主要事实边界；说明放在简历正文之外。\n\n## 原则

只写有依据的真实经历，明确个人贡献与团队成果，避免推测动作、工具和业务效果。材料有限时如实呈现，不强行填充。工具聚焦简历，不默认扩展为职业规划或面试训练。

## 版本

当前标准入口采用开发版 V0.4.1，新增成稿阶段格式询问、关键修改说明及照片和排版检查，并修正排序规则与示例事实来源。此前发布的 v1.0 基于开发版 v0.3.5，保留为历史版本。开发版本号和此前发布名称分别记录，不代表功能回退。\n\n仓库仅发布通用 Skill 与使用说明，不包含私有测试简历、私有方法材料或项目交接记录。
