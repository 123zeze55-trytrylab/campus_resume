# Campus_Resume_SKILL_v1.0

帮助校招生优化已有简历，或从零写出简历的轻量工具。支持不同岗位的定向调整，以及相关方向的通用投递；不承诺同一份简历适合所有岗位。

## 获取与使用

- 下载 [Campus_Resume_SKILL_v1.0.md](./Campus_Resume_SKILL_v1.0.md)，或使用标准入口 [SKILL.md](./SKILL.md)。两份文件内容相同。
- 在支持自定义 Skill 的工具中按其要求加载 `SKILL.md`；也可在新对话中上传文件，请 AI 按文件规则工作。
- 已有简历：上传简历，说明“帮我优化”，或“先诊断，不要直接出全文”。
- 没有简历：说明教育背景和大致方向，零散描述做过的事情即可。
- 想海投：告诉 AI 所考虑的方向；不需要逐个提供 JD。
- 要定向投递：提供具体 JD，直接调整内容重点。

## 输出

默认交付 Markdown 正文；环境支持时生成 `.md` 文件。可按需选择 PDF、HTML 或可编辑 Word，实际文件能力取决于使用环境。默认按适合一页 A4 的内容量取舍；Markdown 本身没有固定分页。

## 原则

只写有依据的真实经历，明确个人贡献与团队成果，避免推测动作、工具和业务效果。材料有限时如实呈现，不强行填充。工具聚焦简历，不默认扩展为职业规划或面试训练。

## 版本

v1.0 的规则内容沿用开发版 v0.3.5，仅调整发布名称。仓库仅发布通用 Skill 与使用说明，不包含私有测试简历、私有方法材料或项目交接记录。
